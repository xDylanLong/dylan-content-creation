# 产品商业化｜30 天研究驱动口播计划

## 系列定位

- 学习目标：学完后，观众能把一个模糊想法拆成明确用户、真实问题、最小可售方案、定价和第一次付费试点。
- 目标观众：有产品想法、正在做工具或服务，但还没有稳定付费用户的人。
- 平台与形式：抖音／小红书，露脸口播或半露脸口播。
- 篇数与频率：30 篇／1 个月日更。
- 单篇时长：约 3 分钟，默认 550–800 个汉字。
- 知识基础：从零开始，沿用 dbs-learning 的学习递进。

## 学习路径

| 阶段 | 篇数 | 阶段目标 |
|---|---:|---|
| 方向与问题 | 01–03 | 看清“做出来”和“卖出去”的差别，找到要验证的付费问题 |
| 基础概念 | 04–08 | 学会识别用户、任务、痛点、价值和第一批人群 |
| 方法与步骤 | 09–15 | 把价值判断变成访谈、MVP、Offer 和定价动作 |
| 案例与反例 | 16–22 | 用假设案例识别免费信号、个案和复购误判 |
| 执行与迭代 | 23–27 | 完成最小销售、交付、验收和第二次销售 |
| 整合与下一步 | 28–30 | 串起商业化闭环，形成下一轮验证计划 |
