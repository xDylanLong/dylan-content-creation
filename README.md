# dylan-series-speaking

> 把产品判断、产品商业化和 AI 产品商业化，整理成可以直接学习、录制和复盘的中文短视频系列。

[English README](README.en.md)

## 这是什么

这是一个面向产品经理、开发者、设计师、运营、创业者和互联网从业者的内容仓库。

仓库里的内容以连续系列的方式组织：每个系列从基础问题开始，逐步进入方法、反例、协作和复盘。每篇文章通常包含选题依据、标题与 Hook、完整口播稿、拍摄提示、内容小结、下一篇预告和事实边界。

## 当前系列

### 1 分钟互联网产品判断

从“需求值不值得做”开始，学习如何识别用户、问题、替代行为、真实代价、优先级和开发风险，最后把判断传递到设计、开发、上线和复盘环节。

学习路径：判断入口 → 核心概念 → 判断方法 → 反例边界 → 协作执行 → 复盘整合。

入口：[1分钟互联网产品判断/00-系列计划.md](1分钟互联网产品判断/00-系列计划.md)

## 典型文章结构

每篇内容尽量同时服务学习和录制：

1. 明确本篇要解决的问题
2. 说明选题研究依据和证据强度
3. 提供标题、封面方向和前几秒 Hook
4. 给出可以直接录制的完整口播稿
5. 补充拍摄提示、可视化材料和收束句
6. 记录事实边界、待补材料和用户反馈

## 研究与证据边界

研究资料用于帮助选择切口、提出问题和检查近期语境，不等于受众规模、平台热度或行业普遍规律的证明。

仓库会区分：

- 已确认的事实和可追溯来源
- 来自公开平台的近期信号
- 课程推导、假设案例和待验证判断

中文平台覆盖可能不完整，部分公开页面也可能无法访问。遇到这类情况，内容会保留日期、来源和覆盖限制，不把稀疏信号包装成“全网趋势”。

## 怎么使用

### 阅读学习

先阅读对应目录的 `00-系列计划.md`，了解学习路径，再按编号顺序阅读文章。每篇末尾的“下一篇预告”和“用户反馈／口播复盘”可以用来继续学习或记录录制反馈。

### 录制口播

打开单篇文章的“口播稿”部分即可作为录制底稿。文中的 `[停顿]`、`[重读]` 等标记用于节奏提示，不需要念出来；假设案例和研究边界应在发布前根据自己的真实场景再次核对。

### 更新内容

涉及新产品、新平台、新政策、近期案例、价格变化或“最新”语境时，应重新检索并在文章中记录研究日期和来源。低时效的概念内容可以复用已有研究，但要说明复用理由和仍需验证的事实。

## 适合谁

- 想系统学习产品判断，而不是只记零散术语的人

- 想将商业化知识加工成连续短视频的人
