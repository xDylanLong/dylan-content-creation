# 连续学习口播骨架

## 研究与教学分工

研究内容只负责确定：

- 系列主题与目标人群；
- 本篇具体选题和唯一问题；
- 现实背景、案例、用户痛点和可验证材料；
- Hook 可以借用的场景、原话或冲突，包括模型／案例本身广为流传的经典一句话（需能在多个独立来源查到同一表述，不是研究时临时总结出来的句子，不够经典就不用）。

研究内容不负责决定正文的教学顺序。研究笔记、平台信号和链接留在创作底稿中；只有能帮助观众理解或行动的材料，才进入口播正文。

## 连续学习推进

每篇完成一轮“小步学习”，必须满足：

1. 接住上一篇已经讲清的结论或真实反馈；
2. 只推进一个主要问题；
3. 先用白话解释核心概念，再增加专业词；
4. 用一个案例把概念落到具体场景；
5. 提炼适合本篇的判断、步骤或边界，可以拆成分点，也可以融入案例和推演；
6. 默认给出一次可以完成、产出可检查结果的练习；如果用户或系列计划明确取消练习，改为一句高密度判断或边界结论；
7. 说明本篇解决了什么，以及下一篇自然会遇到的新问题。

如果本篇需要讲一个和常识不同的新增判断，先单独完成观众已有的常规判断，再用案例结果、对比或追问把它推出来。策划中分别写“已有观点层”和“新增判断层”；口播中不直接说“反直觉观点”“容易被忽略的信号”等结构标签，至少用一个转折句和一个新段落把两层隔开。

## 反馈读取

生成下一篇前，必须读取当前序号最大的文章和末尾的“用户反馈／口播复盘”。只提取用户实际填写的内容，忽略模板提示语。

根据反馈调整：

- 没听懂或概念混乱：降低抽象度，补一个更具体的例子；
- 看懂但没兴趣：更换切入场景，连接真实问题；
- 提出应用问题：增加案例、判断方法和操作步骤；
- 明显掌握：提高概念密度，推进到下一层；
- 没有真实反馈：维持当前难度，小步推进，不擅自假设用户已经掌握。

## 单篇正文骨架

正文按以下顺序组织：

1. 现实问题或具体场景开场；
2. 直接说清本篇要解决的问题；
3. 给出一个核心判断；
4. 用案例解释这个判断；
5. 按本篇选定的主结构推进，例如“观点 → 白话解释 → 例子”，或“场景 → 计算 → 判断”；
6. 只有确实有帮助时，才把内容转成清单、步骤或判断方法；
7. 给观众一个今天能完成的练习；
8. 用小结收束，并留下下一篇问题。

每个分点都要能单独听懂，但不要把某一种版式当成所有课程的模板。先看本篇的唯一问题、观众已有基础、上一轮反馈和可用材料，再选择一种主结构：概念辨析可以用定义和边界；商业判断可以从场景讲到结果；数字问题可以展示一笔假设计算；方法问题可以拆动作和检查标准；复盘问题可以沿着过程、错误和修正推进。公式、列表、对比和案例都只是工具，只有能让这篇更容易理解时才使用。

每个分点同时要具备四个要素，并对应本篇骨架（上面 8 步顺序，或本系列 30 篇总纲里的阶段骨架）里的一步：为什么现在讲这个（承接上一分点留下的结果、缺口或追问）；具体回答骨架的哪一步或哪一个问题；怎么承接上一分点；怎么为下一分点留出钩子，让它的出现显得必然。这四点靠内容本身体现，不写成“这一部分讲……”的报告式提示。抽掉某个分点，如果不影响观众理解，说明它没有对应骨架里的任何一步，应该合并或删除，而不是继续留着凑数。

一篇只保留一种主结构，其他内容围绕它服务。列表可以出现，但不为了完整而添加；每项都要回答具体问题，不能把抽象名词排成漂亮口号。主题适合计算时，可以使用简单的示例数字，让观众看到判断过程。数字必须标为示例或来自可核验材料，不用精确数字制造权威感。没有必要形象化时，不使用比喻；直接说用户做了什么、得到什么、付出了什么。

## 系列单篇固定结构

每篇文件固定包含：

- `本篇要解决的问题`
- `选题研究依据`
- `标题候选`
- `Hook`
- `长文正文` 或 `口播稿`
- `口播提示（仅视频）`
- `本篇小结`
- `下一篇预告`
- `待补素材与事实边界`
- `用户反馈／口播复盘`

其中“选题研究依据”服务于内容判断，正文或口播服务于观众理解；两者不得互相替代。选择视频口播时，`口播稿` 必须从最终 Hook 开始，按 `dylan-content-review` 的人物/场景→异常→证据→缺口→收益关系组织，并包含正文；收益承诺需要被后文承接，但不机械逐字重复。口播应是一段可以直接朗读的完整内容，不附加镜头、画面、分镜或拍摄脚本。选择长文时，正文从具体入口开始，用短段落和必要的配图位置推进阅读。

## 单篇质量检查

- 是否接住上一篇的结论或真实反馈？
- 是否只围绕一个核心问题？
- 是否有核心概念、具体案例和适合本篇的判断或步骤？
- 如果使用分点，每个分点是否都能单独听懂？
- 每个分点是否都能单独回答“为什么现在讲、回答哪个问题、怎么接上一个分点、怎么引出下一个分点”，并且能对应骨架里的一步？
- 是否有可立即完成、结果可检查的练习？
- 是否说明本篇结论和下一篇自然产生的问题？
- 研究内容是否只影响选题、问题、案例和背景？
- 是否把研究资料误写成了正文？
