# 1分钟互联网产品判断 Content Production Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在当前口播系列工作区建立一个面向互联网从业者的 30 集、约 1 分钟竖屏产品判断系列，并交付研究快照、完整总纲和第 01 集录制稿。

**Architecture:** 以一个独立系列目录承载计划、30 集脚本、research 研究文件和 assets 空目录。研究文件保存证据边界；系列计划保存学习梯度；单篇脚本只保留本篇问题、Hook、正文、动作和反馈区。

**Tech Stack:** Markdown 文件；last30days-cn 3.2.0-cn；last30days 3.18.4；中文短视频口播规则。

## Global Constraints

- 系列名：1分钟互联网产品判断。
- 目标观众：产品经理、开发者、设计、运营、增长、创业者及其他互联网从业者。
- 频率：30 集，支持与其他系列交替发布，一天发布一集。
- 时长：每集约 1 分钟；正文约 500–800 个汉字。
- 结构：一个场景、一个问题、常识层、反直觉观点、2–3 个例子、一句高密度结论。
- 研究范围：2026-07-12 至 2026-08-11；中文和全球研究分开保存，并标明稀疏、失败和待验证信号。
